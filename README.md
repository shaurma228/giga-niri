# giga-niri

Оформление для [niri](https://github.com/niri-wm/niri) 26.04 в стиле **Tokyo Glass**: палитра Tokyo Night, матовое стекло, блюр, градиентные рамки и собственные анимации.

Рассчитано на CachyOS/Arch рядом с KDE Plasma: оформление применяется только внутри сессии niri и не меняет темы KDE, GTK и Qt.

Статус: в разработке, см. [PLAN.md](PLAN.md).
